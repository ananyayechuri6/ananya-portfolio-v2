# Ananya Yechuri | Cybersecurity & GRC Portfolio

A clean consulting/risk-management style portfolio for GitHub Pages.

## What this includes
- Consulting / risk management aesthetic
- Article section
- GRC dashboard section
- Resume download placeholder
- Professional photo placeholder
- Experience timeline
- Project pages

## Launch on GitHub Pages
1. Upload these files to your repository.
2. Go to Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /root.
6. Save.

## Important customization
- Put your resume PDF in the `resume` folder and name it `Ananya_Yechuri_Resume.pdf`.
- Put your professional photo in the `assets` folder.
- Replace the photo placeholder in `index.html` when ready.
