SOX Control Testing Case Study

This case study demonstrates how I would document a basic SOX control testing scenario for access management.

Example control

Control objective: Ensure user access is reviewed periodically to prevent unauthorized access.

Testing approach

  • Request user access review evidence.
  • Verify review date, reviewer, population completeness, and documented sign-off.
  • Identify exceptions or missing evidence.
  • Document finding and remediation recommendation.
