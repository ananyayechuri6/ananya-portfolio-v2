Example Control

Access Review Control

Control Objective

Ensure user access is reviewed periodically to prevent unauthorized access.

This control helps confirm that user access remains appropriate based on job responsibilities, role changes, terminations, and business need.

Control Area: Access Management

Frequency: Quarterly

Risk Addressed: Unauthorized access to sensitive systems

Evidence Type: User access review export and sign-off

Testing Workflow

How the control would be tested

01

Request Evidence

Obtain access review export, user population, reviewer sign-off, and review date.

02

Validate Completeness

Confirm the population includes all in-scope users and systems.

03

Review Sign-Off

Verify reviewer approval, review timing, and documented completion.

04

Document Results

Record exceptions, control conclusion, and remediation recommendation.
